# تحديث المحاسب التقني 3.5.12 — صور المواد

- تظهر صور المواد في **العرض الشبكي داخل الفاتورة**، و**قائمة المواد**، و**شاشة إضافة/تعديل المادة** فقط.
- لا تُعرض الصور في البحث السريع أو سطور الفواتير أو الفواتير المطبوعة.
- من بطاقة المادة اختر «من المعرض» أو «التقاط صورة»؛ يمكن تغيير الصورة أو حذفها قبل الضغط على «حفظ».
- تُحوَّل الصورة إلى JPEG مصغّر (حوالي 420 بكسل أو أقل) وتُخزَّن في سجل المادة نفسه (`photoData`).
- النسخ المحلية اليدوية والتلقائية تتضمن صور المواد تلقائياً مع `State.items`؛ والاستعادة تعيد الصور الموجودة في النسخة.
- تبقى جميع المواد القديمة دون صورة صالحة للعمل وتظهر لها أيقونة افتراضية.
- لا تتغير بنية قاعدة البيانات أو معرّف التطبيق أو طريقة حساب الأسعار والمخزون؛ تظل التحديثات فوق النسخ السابقة مشروطة بمفتاح التوقيع نفسه.
- اختبر المعرض والكاميرا على هاتف أندرويد فعلي؛ يتطلب التقاط صورة إذن الكاميرا ووجود تطبيق كاميرا متاح.
- لا تحذف النسخة الأصلية. أنشئ نسخة احتياطية قبل تحديث APK.
