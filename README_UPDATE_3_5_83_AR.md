# إصدار 3.5.83 — إصلاح عملة السندات في تطبيق موظف البيع

## سبب الخطأ
عند عرض `SYP` بصورة `ل.س` في بعض القوائم، كان عنصر `<option>` بلا `value` صريح، فتغيّرت قيمته الداخلية إلى `ل.س`. بروتوكول المزامنة يقبل فقط `SYP` و`USD` في هذه النسخة، وكان الحفظ يظهر رسالة «عملة غير مدعومة في هذه النسخة».

## الإصلاح
- صار تحويل اسم العملة للعرض يحافظ على القيمة الداخلية الأصلية لأي خيار قائمة، فلا يتغير `SYP` إلى `ل.س` في البيانات المحاسبية.
- أصبح زر عملة سند موظف البيع زر تبديل مباشر بين الليرة السورية والدولار، دون قائمة منبثقة، مع بقاء بيانات النموذج عند التبديل.
- يعرض تحرير السند المحفوظ عملته الأصلية ويتيح تبديلها.
- أُعطيت خيارات عملة الفاتورة قيم ISO صريحة كذلك.
- أبقينا إعدادات التحقق الصارمة من رمز العملة في المزامنة؛ لا يتم قبول رموز غير مدعومة بإخفاء الخطأ.
- حُدّثت أرقام البناء: الرئيسي 3.5.83 (versionCode 87) وموظف البيع 3.5.83-field-currency (versionCode 40).

## الفحوصات
81 ملف اختبار Node.js ناجح، وفحص صياغة JavaScript للملفات المعدّلة، واختبار فعلي داخل Chromium لتبديل عملة سند قبض وحفظه بالليرة وسند دفع بالدولار، واستعادة عملة سند عند التعديل مع حماية القيم.

## البناء والتثبيت
افك ضغط المشروع وارفع محتوياته إلى المستودع مع الحفاظ على `.github/workflows`. ملف ZIP مشروع مصدر، وليس APK. لم يجرِ بناء أو تثبيت APK على هاتف فعلي. عند تحديث نسخة مثبتة احتفظ بمعرف الحزمة ومفتاح التوقيع السابقين، وخذ نسخة احتياطية خارجية قبل التجربة.
