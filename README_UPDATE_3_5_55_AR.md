# الإصدار 3.5.55 — معاينة أرصدة الفاتورة أثناء الإنشاء

- الرئيسي والمندوب: أسفل نموذج الفاتورة يظهر الرصيد السابق والرصيد النهائي المتوقع للزبون أو المورد المختار وبعملة الفاتورة حصراً.
- نتيجة الفاتورة غير المدفوعة = الصافي − المدفوع. المبيعات والمردودات والمشتريات وعكسها تُطبّق وفق اتجاه القيد المحاسبي دون تحويل بين الدولار والليرة.
- يتجدد الرصيد المتوقع عند تغيير العميل أو المورد أو البنود أو الخصم أو الضريبة أو نوع الدفع أو قيمة الدفع الجزئي أو عملة الفاتورة.
- في البيع النقدي دون حساب تظهر إشارة — دون خلق رصيد اصطناعي. في جهاز المندوب، إذا لم يصل كشف الأرصدة من الرئيسي، تظهر رسالة عدم توافر الرصيد إلى حين المزامنة.
- عند تعديل فاتورة محفوظة يُستبعد أثرها الأصلي من رصيد ما قبل التعديل، ولا يتم ترحيل القيم المتوقعة إلى قاعدة البيانات قبل حفظ الفاتورة.
- مدمج كذلك تحسين ملخص أرصدة العملاء والموردين، والبحث التفاعلي عن المواد، وتصفية المناقلات حسب مستودع الوجهة من الإصدار الجاري السابق.

فحص المصدر لا يغني عن تجربة على جهاز فعلي ونسخ احتياطي. الحزمة لا تتضمن مفاتيح توقيع ولا بيانات تشغيل.
