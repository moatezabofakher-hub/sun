# المحاسب التقني الرئيسي 3.5.28 + المندوب 1.2.0 — مزامنة محلية بضغطة واحدة

## ما أُضيف

- اتصال محلي بين هواتف أندرويد على شبكة Wi-Fi نفسها باستخدام Android NSD/mDNS وخادم TCP محلي؛ دون إنترنت أو اشتراك أو اختيار ملفات JSON.
- عند فتح شاشة «مندوبو التوزيع» في الرئيسي يبدأ الاستقبال تلقائيًا، ويظهر مؤشر «الاستقبال جاهز» عند نجاح بدء الخدمة.
- يضغط المندوب زر «مزامنة الآن — Wi-Fi محلي» في الرئيسية أو شاشة المزامنة.
- تُرسل العمليات غير المرحّلة، ويُتحقق من الشركة والمندوب والمستودع والأصناف والعملات، ثم تُحفظ الفواتير والسندات في قاعدة الرئيسي.
- بعد حفظ البيانات يرجع تأكيد مشفّر؛ يحدث التطبيق الفرعي قائمة الأصناف والأسعار والعملاء ورصيد السيارة ومؤشر العمليات المتزامنة.
- إعادة إرسال العمليات بعد انقطاع الشبكة لا تكرر الفواتير ولا السندات. إذا تعطل حفظ إحدى القاعدتين لا تظهر حالة نجاح مضللة.
- تبقى ملفات TA_Ops وTA_ACK وTA_Provision وسيلة احتياطية عند تعذر اتصال الهواتف عبر الشبكة.

## التحضير (مرة في كل جلسة)

1. ثبّت النسختين الموقّعتين الجديدتين باستخدام مفاتيح GitHub Secrets نفسها. احتفظ أولًا بنسخة احتياطية منفصلة من بيانات كل تطبيق، ولا تحذف أي نسخة.
2. هاتف المندوب يجب أن يكون مُجهّزًا ومرخّصًا عن طريق ملف TA_Provision ورمز تفعيل TAF1، كما في الإصدار السابق. المزامنة الجديدة تلغي اختيار ملف العمليات اليومي، لا متطلبات الاقتران الأولى.
3. وصّل الهاتفين على شبكة Wi-Fi واحدة تسمح باتصال الأجهزة بعضها ببعض (من دون AP/client isolation). إذا استخدمت نقطة اتصال، تأكد أنها تسمح بأجهزة الشبكة المحلية.
4. على هاتف الإدارة افتح «المحاسب التقني الرئيسي ← مندوبو التوزيع» واتركه مفتوحًا. يجب أن تظهر عبارة «✅ الاستقبال جاهز».
5. على هاتف المندوب اضغط «⇄ مزامنة الآن بضغطة واحدة» في الصفحة الرئيسية أو شاشة المزامنة. لا تدخل إلى الملفات.
6. انتظر التأكيد في شاشة المندوب. إذا أظهر عدد عمليات غير متزامنة، لا تحذفها؛ أعد المحاولة بعد معالجة سبب التعذر.

## الحماية والموثوقية

- تُشفّر الرسائل على الشبكة محليًا باستخدام AES-GCM 256-bit بمفتاح مشتق من سر الاقتران المنقول أصلًا داخل ملف التجهيز. هويات الشركة والمندوب فقط ظاهرة خارجيًا.
- يُستخدم رقم تحدٍّ عشوائي لكل محاولة؛ لا يقبل المندوب تأكيدًا قديمًا مرسلًا لعملية أخرى.
- بيانات المندوب الأصلية لا تُحذف عند التأكيد؛ تُوسم بأنها سُلِّمت، ويظل التاريخ محفوظًا.
- تُجرى المزامنة فقط على سجل المعاملات، وليس عن طريق نسخ قاعدة بيانات المندوب فوق قاعدة الشركة.
- نجاح الترحيل لا يعني أنه جرى اختبار التجربة كاملة على أندرويد. يجب إجراء اختبار بأرقام وفواتير تجريبية ومطابقة رصيد السيارة والكشوف قبل الاستخدام التجاري.
- لا يزال ملف تجهيز المندوب الأصلي JSON يتضمن بيانات وسر الاقتران؛ انقله بسرية إلى الجهاز المعتمد، ولا تنشره في مجموعة عامة أو GitHub.

## حالات تعذر المزامنة

- «لم يظهر التطبيق الرئيسي» → افتح شاشة المندوبين في الرئيسي، وراجع شبكة Wi-Fi، وإعدادات العزل بين الأجهزة، والأذونات والشاشة المفتوحة.
- «المندوب غير معروف» → تأكد من عدم أرشفته أو إيقافه، ومن تطابق الشركة وملف التجهيز.
- «المخزون لا يكفي» → راجع مناقلات بضاعة السيارة واعتمد الصفقات بعد مطابقة الجرد.
- «لم يتم ترحيل البيانات» → لا تفترض النجاح. أصلح الخطأ، ثم أعد ضغطة المزامنة؛ معرّفات العمليات تحمي من التكرار.
- قد تمنع سياسات بعض شبكات الضيوف/المكاتب اكتشاف الهواتف. يمكن حينها استخدام ملفات JSON يدويًا كما في السابق.

## البناء على GitHub

- الرئيسي: Actions → Technical Accountant - Signed APK → Run workflow → APK المُوقّع.
- المندوب: Actions → Technical Accountant - Agent Signed APK → Run workflow → APK المُوقّع.
- رقم بناء الرئيسي: 35 وإصداره 3.5.28. رقم بناء المندوب: 3 وإصداره 1.2.0.
- لا يلزم إنشاء مفاتيح APK جديدة؛ لا تضع ملف مفتاح تفعيل المندوب الخاص في المستودع.

## حالة التحقق

نجحت اختبارات بروتوكول التشفير، ومنع التكرار، والتراجع عند فشل الحفظ، ومقاومة إعادة تشغيل التأكيد، وفحوص JavaScript السابقة. تم فحص تركيب شفرة جافا باستخدام Javac مع نماذج Android شكلية. لم يُنفّذ بناء APK كامل، ولم نختبر اكتشاف NSD على هاتفين أو نقل ملف من شبكة واقعية؛ لهذا ينبغي اعتبار الاتصال المباشر تجريبيًا حتى يُختبر على الأجهزة ويُقارن أرصدة المحاسبة.
