# تحديث 3.5.91 — حماية مزامنة الكمبيوتر والهاتف
- يلزم إدخال كلمة سر الحماية الحالية عند فتح قسم مزامنة الموبايل والكمبيوتر في إعدادات الرئيسي وويندوز.
- عند عدم إعداد كلمة سر، يبقى القسم مغلقاً حتى إعدادها من إعدادات الحماية.
- إضافة مؤشر مستقل باسم «متصل» بجانب عداد موظفي البيع في الشريط العلوي. أخضر عند وصول مزامنة موثقة حديثاً (خلال 20 ثانية)، وأحمر فاتح خلاف ذلك.
- لا يعطّل هذا القفل المزامنة التلقائية بالخلفية، ولا يغيّر بيانات الفواتير أو رمز الاقتران.
- يلزم بناء APK/EXE باستخدام GitHub Actions. لم يُختبر البناء على أجهزة فعلية.
