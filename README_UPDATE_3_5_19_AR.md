## ما تغير
- إزالة لوحة «مركز إدارة الأعمال» العلوية من الرئيسية، مع إبقاء أزرار العمليات والأقسام.
- وضع «الضبط» بجانب «التقارير» ضمن شريط التنقل السفلي المكوّن من ستة أزرار.
- تحسين البطاقات والأيقونات باستخدام تدرجات، ظل مرتفع وحالة ضغط بارزة — دون إنترنت.
- تبسيط قائمة المواد: اسم المادة، صورتها، رصيد المستودع المحدد، مع أزرار الفتح/التعديل والحذف فقط.
- التبديل بين قائمة المواد والشبكة المجمّعة حسب تصنيف الأصناف؛ البحث والتصفية يعملان في النمطين.
- تفاصيل المادة (العملة، الوحدات، الأسعار، الربط) تبقى في نافذة تحرير المادة.

## التحديث على GitHub من الهاتف
1. احتفظ بنسخة احتياطية من بيانات التطبيق المثبت وتحقق من إمكانية استعادتها.
2. فك ZIP داخل الملفات المعدلة فقط. لا ترفع ملف ZIP إلى الجذر وتتوقع أن تتغير الملفات داخله.
3. استبدل `app/src/main/assets/www/index.html` و`app/build.gradle` في مساريهما الأصليين. اختبارات الانحدار المعدلة موجودة أيضًا داخل ZIP.
4. أكّد تغييرات GitHub باستخدام Commit changes على الفرع main.
5. شغّل Actions > Technical Accountant - Signed APK، ثم حمّل APK الموقّع من Artifacts.
6. لتثبيت APK فوق التطبيق السابق يجب تطابق مفتاح التوقيع ومعرّف الحزمة، وأن يكون رقم الإصدار أعلى. لا تحذف النسخة المثبتة إذا رفض أندرويد التثبيت؛ احفظ بياناتك أولًا.
