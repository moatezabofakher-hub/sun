# تصحيح القائمة المنبثقة لعملة تسعير المادة — 14 تشرين الثاني 2026

- التطبيق الرئيسي: 3.5.58 (versionCode 65، بدلاً من 64).
- تطبيق المندوب: 3.5.56 بلا تغيير (versionCode 24).
- التطبيق المستقل Solo: 3.5.56 (versionCode 13، بدلاً من 12).

## سبب الخطأ

كانت نافذة اختيار عملة تسعير المادة تستخدم صنف Tailwind باسم `z-[9999]` غير موجود في ملف CSS المُجمّع Offline، لذلك فقدت أولوية الظهور أحياناً، وأصبحت خلف بطاقة المادة ولا تظهر إلا عند إغلاقها.

## الإصلاح

- تثبيت `z-index:11000` و`position:fixed` مباشرة على غلاف قائمة اختيار العملة ليظهر دائماً فوق بطاقة المادة.
- حذف النافذة المتداخلة عند إغلاق بطاقة المادة أو فتح نموذج آخر.
- زر الرجوع يغلق قائمة العملة أولاً دون إسقاط تغييرات بطاقة المادة غير المحفوظة.
- الحفاظ على رمز العملة داخل الزر بعد الاختيار، وعدم تغيير بيانات الحسابات أو الفواتير.
- إضافة اختبار لظهور الطبقة في أندرويد والاختيار والإغلاق.

## التثبيت

ارفع ملفات المشروع الكامل إلى المستودع المناسب أو انسخ ملفات التحديث إلى **المسارات نفسها داخل المشروع المطابق فقط** ثم ابنِ APK جديداً. تطبيق المندوب لا يحتاج تحديثاً لهذا الإصلاح. استخدم مفتاح التوقيع الأصلي واحتفظ بنسخة احتياطية قبل تثبيت APK. هذا مشروع مصدر وليس APK موقّعاً. لم يتم إجراء اختبار على جهاز أندرويد فعلي.

**لا تنسخ مفاتيح التوقيع أو ملفات الأسرار إلى المستودع.**
