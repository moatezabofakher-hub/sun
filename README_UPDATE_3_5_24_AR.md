# المحاسب التقني — تحديث المظهر ثلاثي الأبعاد 3.5.24

هذا تحديث بصري فوق الإصدار 3.5.23، مصمم للهاتف ومن دون إنترنت. لا يتضمن مواد أو فواتير تجريبية.

## ما تغير

- نظام ألوان موحّد بالكحلي والأخضر البحري، وخلفيات هادئة.
- أيقونات بارزة ثلاثية الأبعاد في الرئيسية والشريط السفلي وأقسام الضبط وبطاقات المواد.
- أزرار للعمليات والمواد والطباعة والتقارير بتدرجات وظلال متناسقة واستجابة للمس.
- تحديث مظهر النوافذ المنبثقة، ونوافذ الحفظ والتأكيد والحماية، والحقول والقوائم.
- إكمال رموز SVG المحلية التي كانت قد لا تظهر (الرسوم البيانية، الدعم، الصور، وبعض علامات التنقل)، وإصلاح أيقونتي اللغة والشركة بحيث تظهران بخطوطهما الصحيحة دون اتصال.
- الحفاظ على تصميم الفواتير والفواصل المنقطة وترقيم الأصناف والتقارير والحسابات المستقلة.
- عرض الإصدار 3.5.24 داخل الضبط.

## معلومات التحديث

- `versionCode`: 31، `versionName`: `3.5.24-premium-3d-ui`.
- معرّف التطبيق ثابت: `com.sunshine.technicalaccountant`.
- اسم قاعدة البيانات ثابت: `AlRaedAccountingERP_v2`.
- إعدادات إصدار APK الموقّع في `.github/workflows/signed-release.yml` لم تتغير.
- لا تتضمن الملفات أي مفتاح توقيع خاص أو كلمات مرور.

## رفع الملفات المعدّلة إلى GitHub

1. فك ضغط `UPDATE_3_5_24_CHANGED_FILES.zip` على الهاتف أو الكمبيوتر.
2. استبدل **كل ملف داخل مساره الأصلي** في مستودع `moatezabofakher-hub/sun`؛ رفع ZIP بمفرده لا يستبدل محتوياته.
3. أهم الملفات: `app/src/main/assets/www/index.html` و `app/src/main/assets/www/static/icons.js` و `app/build.gradle`.
4. افتح **Actions → Technical Accountant - Signed APK** وشغّل **Run workflow** من الفرع `main`.
5. حمّل APK من **أحدث** عملية بناء ناجحة. تحقق من ظهور `3.5.24` في صفحة الضبط بعد تثبيته.
