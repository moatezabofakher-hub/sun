# تحديث المحاسب التقني الرئيسي 3.5.54 — 14 تشرين الثاني 2026

التحديث مبني على الإصدار 3.5.53 ويحتفظ بمعرّف التطبيق وقاعدة بياناته.

## الجديد

1. **ملخص أرصدة العملاء والموردين:** عند فتح «الحسابات» ثم «العملاء» أو «الموردون» يظهر في أعلى القائمة مجموع الأرصدة المدينة والدائنة، منفصلين بعملتي SYP وUSD. يعتمد على الأرصدة الفعلية للحسابات من دون مقاصة أو تحويل عملة، ويشمل كل حسابات النوع المختار مهما كان نص البحث.
2. **بحث المواد المباشر:** البحث بالاسم أو الباركود يحدّث القائمة/الشبكة عند كل ضغطة، ويحدّث عداد النتائج، ويستعيد المواد فور حذف البحث. يدعم تطبيع حروف العربية والتشكيل.
3. **سجل مناقلات المستودع المستلم:** تعرض العمليات الأخيرة أسفل بطاقة المناقلة فقط الفواتير التي وجهتها خانة «إلى المستودع». يتغير السجل فور تغيير المستودع أو فتح فاتورة مناقلة للتعديل، بينما تبقى جميع العمليات محفوظة ومتاحة في قاعدة البيانات.

## بناء النسخ

- المشروع يحتوي الرئيسي في `app/` والمندوب في `field_agent/`، مع ملفات GitHub Actions والاختبارات.
- التطبيق الرئيسي: `versionName 3.5.54-summary-search-transfer`.
- المندوب لم يتطلب تعديل في هذا التحديث وبقي بنفس إصدار المصدر السابق.
- لا تتضمن الحزمة أي مفاتيح توقيع خاصة. استخدم الأسرار الأصلية المخزّنة في GitHub Secrets.
- احفظ نسخة احتياطية من قاعدة بيانات التطبيق قبل تثبيت APK تجريبي/إصدار جديد.
