# المحاسب التقني — نقطة بيع موظف البيع وصوت الباركود

## النسخ
- ويندوز الرئيسي 3.5.62
- أندرويد الرئيسي 3.5.63 — versionCode 70
- أندرويد موظف البيع 3.5.63 — versionCode 29
- أندرويد المستقل 3.5.60 — versionCode 17

## التعديلات
- تطبيق موظف البيع: واجهة مستقلة لنقطة البيع النقدية، تختلف عن فاتورة المبيعات التقليدية؛ فيها شبكة مواد، قائمة أسماء، كاميرا باركود، سلة بيع، الكميات والأسعار، الحسم والإضافات والحفظ والطباعة.
- تبقى نقطة البيع مبيعات نقدية محفوظة عبر المحرك الحالي، مع تحديد المصدر agent-pos للاطلاع والتعديل والمزامنة دون إنشاء دفتر محاسبي مستقل.
- جميع التطبيقات: زمور تأكيد قصير عند إضافة المادة عن طريق الباركود بنجاح، بما فيها المسح بالماسح الخارجي والكاميرا والقراءات المتكررة؛ لا يصدر الصوت عند فشل الإضافة.
- أندرويد: صوت أصلي عن طريق ToneGenerator؛ ويندوز: صوت WebAudio. يعتمد السماع على مستوى الصوت وعدم الكتم في الجهاز.

## رفع وبناء المشاريع
ارفع كل مشروع مفكوكاً إلى مستودعه المخصص، أو ارفع ZIP واحداً إلى المستودع الذي يستخدم GitHub Actions لفك ZIP (يجب تعديل اسم الملف في workflow عند تغيير الاسم).
مشروع أندرويد الرئيسي وموظف البيع يحتوي مجلدي app و field_agent مع ملفات GitHub Actions.
مشروع ويندوز يحتوي package.json و .github/workflows/windows-installer.yml و src و web و assets.
احتفظ بمفاتيح التوقيع القديمة ونسخ احتياطية من البيانات قبل تثبيت أي تحديث. هذه ملفات مصدر ولم يتم اختبار APK/EXE جديد فعلياً على جهاز.
