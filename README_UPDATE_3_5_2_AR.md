# المحاسب التقني – تحديث 3.5.2: إظهار أزرار الإضافة

## ما الذي تغيّر؟
- أصبح زرا «إضافة مستودع» و«إضافة مصروف» في الرئيسية بخلفية واضحة ونص وأيقونة بلون أبيض.
- تم تطبيق نفس الأسلوب على «إضافة مستودع»، «مناقلة مواد» داخل صفحة المستودعات، وأزرار الحفظ والإضافة ذات الصلة.
- استخدمت قواعد CSS ذات أولوية عالية للتغلب على تعارض تنسيقات WebView أو الأنماط العامة.
- لم تُمس معادلات الحسابات، حركة المخزون، سجلات الفواتير، الكاميرا، إعدادات الطباعة، النسخ الاحتياطي أو التفعيل.

## حماية بيانات المستخدم
- لا يغيّر هذا التحديث معرّف الحزمة `applicationId` أو اسم قاعدة IndexedDB `AlRaedAccountingERP_v2` أو مفاتيح التخزين.
- من أجل تثبيت **تحديث** فوق التطبيق القديم لا بد من تطابق توقيع APK؛ GitHub Actions الذي يبني ملفات Debug بمفتاح مؤقت قد ينتج توقيعاً مختلفاً.
- قبل أي تثبيت صدّر نسخة احتياطية JSON من داخل التطبيق وخزّنها خارج الهاتف إن أمكن. لا تزل التطبيق الحالي عند تعذّر التحديث أو قبل التأكد من سلامة النسخة الاحتياطية.
- نسخة الاختبار المنفصلة لها اسم حزمة مختلف، فلا تتشارك البيانات تلقائياً مع النسخة القديمة.

## بناء APK عبر GitHub Desktop
1. فك ضغط حزمة ZIP.
2. من GitHub Desktop اختر مستودع `sun` واضغط Show in Explorer.
3. انسخ **محتويات** ZIP إلى جذر المستودع مباشرة بما فيها `.github` و `app` و `tests`. لا تنسخ المجلد الخارجي نفسه.
4. نفّذ Commit to main ثم Push origin.
5. افتح Actions وحمّل APK من آخر محاولة بناء ناجحة.

**تأكد بعد التثبيت من وضوح خلفيات الأزرار في الرئيسية والمستودعات والمصاريف.**
