# المحاسب التقني — تحديث المناقلات 3.5.26

**الأساس:** المشروع الموحد للإدارة والمندوب، تطبيق الإدارة 3.5.25، رقم بناء Android 32.

**الإصدار الجديد:** تطبيق الإدارة 3.5.26، `versionCode 33`، ومعرّف التطبيق ثابت `com.sunshine.technicalaccountant`. لم تتغير هوية التوقيع الدائم أو قاعدة البيانات.

## التعديلات

- من «المستودعات والمناقلات» ← «مناقلة مواد» تظهر **شبكة المواد**.
- البحث المباشر باسم المادة، واختيار المجموعة أو جميع المجموعات.
- الضغط على بطاقة المادة يضيفها لقائمة المناقلة، والضغط مرة ثانية يزيلها.
- يمكن إضافة **عدة أصناف**، لكل صنف كمية ووحدة قياس مستقلة. يظهر رصيد المصدر.
- زر حفظ المناقلة الجديد أخضر واضح بتباين مرتفع وتصميم ثلاثي الأبعاد.
- يتم **التحقق من جميع الصفوف** قبل الحفظ؛ إذا تجاوز صنف واحد رصيده، لا يُحفظ أي منها.
- كل صنف يُخزن بحركة مناقلة مستقلة من نوع السجلات القديمة، مع `batchId` مشترك؛ حفظ المجموعة يتم في استدعاء تخزين واحد.
- لا يتغير المخزون الإجمالي ولا الأرباح؛ يتغير رصيد المستودع المرسل والمستلم فقط.
- تظل إدارة المندوب ومزامنة ملفات التبادل في المشروع كما كانت.

## تحديث GitHub من الهاتف

1. احفظ نسخة احتياطية خارجية من بيانات المحاسبة في التطبيق الرئيسي قبل التثبيت.
2. فك ضغط `TA_UPDATE_3_5_26_CHANGED_FILES.zip`.
3. ارفع الملفات **داخل مجلداتها الأصلية** في مستودع GitHub، واستبدل الملفات القديمة دون رفع ملف ZIP كملف واحد.
4. أهم ملفين للتحديث:
   - `app/src/main/assets/www/index.html`
   - `app/build.gradle`
5. بقية الملفات في الحزمة اختبارات برمجية يتم وضعها داخل `tests/`.
6. شغّل `Technical Accountant - Signed APK` من GitHub Actions عبر الفرع `main`، وليس عملية Debug القديمة.
7. بعد نجاح البناء حمّل آخر Artifact، وفك الضغط، وثبّت ملف APK فوق التطبيق الموجود بنفس التوقيع.
8. تأكد من أن الإصدار الظاهر داخل الضبط أصبح `3.5.26` وأن رقم البناء في `app/build.gradle` هو `33`.

**مهم:** لا تحذف تطبيق الإدارة القديم أو بياناته لتثبيت التحديث. إذا رفض التثبيت بسبب تعارض توقيع أو إصدار، أوقف المحاولة واحتفظ بنسخة احتياطية.

## نتائج الاختبار

- تشغيل جميع اختبارات JavaScript وPython المضمنة في المشروع.
- اختبار جديد لفحص البحث وتصفية المجموعات وتحديد صنفين بوحدتين مختلفتين وحفظهما في حركة واحدة.
- فحص منع حفظ جزء من المجموعة إذا كانت كمية أحد الصفوف زائدة، واسترجاع الحالة السابقة عند فشل تخزين البيانات.
- اختبار شكل الواجهة في Chromium بعرض 390px دون تجاوز أفقي.
- لم يتم بناء APK محليًا ولا إجراء تجربة على هاتف فعلي بعد.

**ملاحظة:** أسماء مواد المعاينة بالصور موجودة داخل بيئة اختبار المتصفح فقط، ولا تتضمن حزمة التحديث أي بيانات محاسبية تجريبية.
