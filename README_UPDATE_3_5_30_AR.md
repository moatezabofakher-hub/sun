# تحديث المزامنة ثنائية الاتجاه — المحاسب التقني

## الإصدارات
- الرئيسي: 3.5.30 (`versionCode 37`).
- المندوب: 1.2.2 (`versionCode 5`).

## التغييرات
1. نقل زر المزامنة إلى صفحة «مزامنة» في الشريط السفلي وحدها، وإزالة بطاقات المزامنة المكررة من الصفحة الرئيسية للمندوب.
2. زر واحد «مزامنة الآن — إرسال واستقبال» يرسل العمليات غير المرحّلة، ثم يستقبل قائمة المواد والأسعار والعملاء والمجموعات وسعر الصرف ورصيد سيارة المندوب، إضافة إلى تأكيد العمليات المستلمة.
3. حتى عند عدم وجود عمليات جديدة لدى المندوب، يرسل التطبيق طلبًا آمنًا للحصول على آخر بيانات الشركة.
4. إظهار تاريخ آخر مزامنة ناجحة، وعدد المواد والعملاء والأرصدة التي تغيّرت، وعدد العمليات المؤكدة.
5. عدم اعتماد تحديثات المندوب إلا بعد حفظ قاعدة البيانات محليًا؛ في فشل الحفظ تعود الحالة القديمة. منع استلام كشف يخص مستودعًا مختلفًا.
6. بقي تبادل ملفات JSON خيارًا احتياطيًا داخل «الطريقة الاحتياطية: مزامنة عبر الملفات».

## الاستخدام على هاتفين
1. شغّل الرئيسي والإضافي بإصدارات موقعة صحيحة، وخذ نسخًا احتياطية قبل التحديث.
2. وصّل الهاتفين بشبكة Wi-Fi واحدة تسمح بالاتصال بين الأجهزة.
3. افتح «مندوبو التوزيع» داخل الرئيسي وانتظر إشارة جاهزية استقبال البيانات. يجب أن يظل التطبيق الرئيسي مفتوحًا.
4. من تطبيق المندوب افتح تبويب «مزامنة» في الشريط السفلي واضغط «مزامنة الآن — إرسال واستقبال».
5. تأكد من ظهور تاريخ آخر مزامنة والملخص، ثم افحص رصيد السيارة والمبيعات في كلا الجهازين.

## التثبيت من GitHub
ارفع الملفات من حزمة التغييرات في مساراتها الأصلية إلى `main`. لا ترفع ملف ZIP نفسه داخل المستودع باعتباره مصدر البرنامج. ثم شغّل عمليتي:
- `Technical Accountant - Signed APK` للرئيسي.
- `Technical Accountant - Agent Signed APK` للمندوب.

أسرار التوقيع الدائم الأربعة السابقة لم تتغير، وكذلك `applicationId` لكل تطبيق. لا تحذف التطبيق السابق ولا تمسح بياناته. احتفظ بنسخة احتياطية مستقلة من بيانات الرئيسي والمندوب.

## اختبار الجودة والحدود
تجارب برمجية شملت مزامنة خالية من العمليات (طلب التحديث فقط)، تطبيق أسعار وأرصدة محدثة، منع تكرار الترحيل، رفض المستودع الخطأ، واسترجاع الحالة عند فشل الحفظ، وفحوص Android WebView. عُرضت الواجهات في Chromium دون أخطاء JavaScript.

لم يتم إنشاء APK أو إجراء اتصال Wi-Fi حقيقي بين هاتفين ضمن بيئة التطوير هذه. لا يمكن ضمان عدم وجود أخطاء تشغيلية على الأجهزة قبل اختبارها فعليًا. قد تفشل المزامنة إذا كان Wi-Fi يعزل الأجهزة أو أغلق تطبيق الإدارة.
