# تحديث المحاسب التقني 3.5.9 — المنازل العشرية للكميات والأسعار

- من **الضبط ← المواد ← عدد الخانات بعد الفاصلة العشرية للكميات والأسعار** يمكنك اختيار 0 أو 1 أو 2 أو 3 أو 4 خانات.
- يتغير عرض الكميات، وأسعار شراء وبيع الوحدات، وأسعار المواد في شبكة الفاتورة، والسعر الإفرادي في الفواتير المعروضة والمطبوعة، ومنها الطباعة الحرارية.
- حقول إدخال الأسعار تظهر العدد المحدد من الخانات عند عدم تحريرها، وعند لمس الحقل تظهر القيمة الأصلية كاملة لتحريرها دون فقد الكسور. حين تحفظ المادة أو الفاتورة تبقى القيم الأصلية والحسابات دقيقة ولا يُطبَّق أي تقريب على البيانات المخزنة بسبب هذا الإعداد.
- **تنبيه محاسبي:** مبالغ إجمالي الفاتورة، والخصم والديون وأرصدة الصندوق تبقى حسب قواعد دقة العملة الحالية (USD منزلتان، SYP بدون كسور). هذا الخيار يتحكم بعرض أسعار المواد ولا يغيّر التقريب المحاسبي أو سعر الصرف.
- تظل كافة تغييرات النسخة 3.5.8 متضمنة (زر الضبط العلوي وتقييم المستودع).
- النسخة الأساسية تحتفظ بمعرّف الحزمة وبيانات التطبيق عند التحديث بنفس مفتاح التوقيع. أنشئ نسخة احتياطية أولاً ولا تحذف التطبيق الأصلي.
- النسخة التجريبية المنفصلة لها معرّف حزمة مستقل.
- ملفات ZIP مشاريع أندرويد قابلة للبناء وليست ملف APK مباشر.
