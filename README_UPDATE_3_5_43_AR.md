# المحاسب التقني 3.5.43 — نسخ المندوب وواتساب ومشاركة PDF الفواتير

## تطبيق المندوب

من **الضبط ← النسخ الاحتياطي التلقائي وواتساب**:

- رقم واتساب المرسل (للتعريف؛ الرقم الفعلي المستخدم يعتمد على حساب واتساب المفتوح على الجهاز).
- رقم واتساب المستقبل (رمز الدولة مطلوب، مثل `+9639...`).
- زر حفظ الرقمين؛ تُحفظ الأرقام محلياً في إعدادات تطبيق المندوب.
- زر اختيار/تغيير مجلد النسخ المحلي، وتفعيل نسخة كل 6/12/24 ساعة أو إيقافها، وزر «نسخ الآن»؛ بقيت النسخ التلقائية إلى المجلد قائمة.
- حفظ لقطة متسقة من بيانات المندوب بعد نجاح حفظ IndexedDB، حتى يستطيع عامل WorkManager إنشاء نسخة في المجلد والجهاز مغلق. تشمل النسخة سجل المندوب وحساباته وأصنافه وبيانات الربط. يُحفظ محتوى النسخة JSON مع `data.agentState` لتمييزه عن نسخة الرئيسي.
- «مشاركة أحدث نسخة عبر واتساب» ينشئ ملفاً مؤقتاً داخل ذاكرة التخزين المؤقت ويفتح شاشة مشاركة أندرويد. على المستخدم اختيار واتساب والتأكد من المحادثة والضغط على «إرسال»؛ **لا يعني حفظ الرقمين أن الإرسال يتم تلقائياً**.

### شرط إرسال واتساب دون تدخل
واتساب العادي لا يسمح بنقل مرفق تلقائياً من هاتف إلى هاتف بمجرد حفظ الرقمين. الإرسال الآلي الحقيقي يتطلب إعداد Meta WhatsApp Business Platform / Cloud API وربط رقم الأعمال وتفويض الاتصال بطريقة آمنة. لم يُضف رمز وصول أو خادم أو وعد بإرسال آلي غير موجود. يحفظ التطبيق نسخ المجلد تلقائياً ويتيح المشاركة اليدوية المباشرة من نفس الشاشة.

**تنبيه أمني:** نسخة بيانات المندوب تحتوي على بيانات تجارية وسجل العمليات وبيانات ربط الجهاز، لذا اختر رقماً موثوقاً، واحفظ نسخة المجلد في موقع آمن.

## التطبيق الرئيسي

- زر **«إرسال PDF»** من معاينة الفاتورة، وزر **«مشاركة الفاتورة PDF مباشرة»** من قائمة إجراءات الفاتورة.
- يُعدّ التطبيق ملف PDF عربي متعدد الصفحات باللوغو واسم الشركة ورقم الهاتف وحساب الزبون وأصناف الفاتورة ومجموعها والمدفوع والمتبقي والأرصدة إن كانت متوفرة.
- يُستخدم ملف مؤقت داخل مجلد Cache الداخلي الذي يملكه التطبيق ويُشارك باستخدام FileProvider بإذن قراءة مؤقت، **دون فتح نافذة «حفظ باسم» أو إنشاء ملف دائم في Downloads**. حذف ملفات المشاركة المؤقتة القديمة عند مشاركة جديدة بعد 24 ساعة.
- وظيفة «حفظ PDF» السابقة لتقارير الديون والمواد بقيت كما هي دون تعديل.

## التثبيت والتحقق

- لا تتغير معرّفات حزم أندرويد أو أسماء قواعد البيانات، ويرتفع `versionCode` للتطبيقين.
- استعمل مشروع الإصدار الكامل، أو ادمج الملفات المعدلة في مشروع 3.5.42 ثم ابنِ التطبيقين عبر GitHub Actions بنفس مفتاح التوقيع السابق.
- قبل التحديث أنشئ نسخة احتياطية مستقلة من الرئيسي والمندوب. لا تحذف التطبيقين الحاليين.
- تم اختبار منطق واجهات JavaScript وربط واجهات Android وفحص صياغة Java. لم يُبنَ APK أو يُختبر واتساب أو ملف PDF على جهاز أندرويد فعلي في هذه البيئة.
