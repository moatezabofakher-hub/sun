# المحاسب التقني 3.5.20 — إصلاح إغلاق أقسام الضبط عند التنبيه

## سبب المشكلة والإصلاح
في الإصدار السابق كانت بعض خيارات الضبط تستدعي إعادة رسم الشاشة بعد حفظ الإعداد، فتُغلق لوحة الإعدادات المفتوحة ويعود التمرير إلى أعلى الصفحة. أصلح التحديث ذلك عبر الاحتفاظ بالقسم المفتوح وموضع التمرير عند التحديث، ومنع أحداث الإغلاق القديمة الصادرة عن عناصر أُزيلت أثناء إعادة الرسم من التأثير على الواجهة الجديدة.

## النتائج المتوقعة
- عند ضبط حجم الخط أو نوع العملة أو المنازل العشرية وحفظ القيمة، يبقى قسم الضبط الحالي مفتوحاً.
- عند ظهور إشعار تحذيري (مثلاً إدخال رمز عملة غير صالح)، يبقى قسم الضبط مفتوحاً وتظل المدخلات ظاهرة.
- فتح قسم مختلف يُغلق القسم السابق كالمعتاد. والخروج من صفحة الضبط يُغلق جميع أقسامها حسب سلوك التطبيق الأصلي.
- لم يُعدَّل أي سجل محاسبي، ولا أسلوب حفظ قاعدة البيانات، ولا مفتاح التوقيع.

## طريقة تحديث الملفات على GitHub من الهاتف
1. انسخ بياناتك احتياطياً من التطبيق المثبت وتأكد من سلامة الملف.
2. فك ZIP الخاص بالملفات المعدلة. لا ترفع ZIP كما هو إلى المستودع.
3. استبدل `app/src/main/assets/www/index.html` و`app/build.gradle` داخل مسارهما الأصلي مع الملفات الاختبارية المُرفقة داخل `tests/` إن رغبت.
4. احفظ Commit changes، ثم شغّل GitHub Actions > Technical Accountant - Signed APK.
5. حمّل ملف APK الموقّع من Artifacts. قبل التثبيت تحقق من أن اسم الملف ليس app-debug.apk.
6. إذا رفض أندرويد التثبيت فوق النسخة السابقة فلا تحذف التطبيق قبل تأمين بياناتك؛ قد تكون المشكلة في عدم تطابق مفتاح التوقيع.
