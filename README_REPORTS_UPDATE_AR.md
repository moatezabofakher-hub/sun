# المحاسب التقني — تحديث صفحة طباعة التقارير — 2026-11-15

## التعديل
- نقل زري "تقرير المواد" و"تقرير الديون" من الشاشة الرئيسية إلى صفحة التقارير.
- أضيف خيار بارز باسم "طباعة تقرير". عند الضغط تظهر قائمة لاختيار تقرير المواد أو تقرير الديون.
- اختيار أي تقرير يفتح معاينة حقيقية تحتوي التفاصيل والإجماليات وأيقونتي طباعة وPDF في أعلاها.
- تقرير المواد يحتفظ بفلاتر التاريخ وموظف البيع في التطبيق الرئيسي، وتقرير الديون يحتفظ بخياري لنا/علينا.
- الطباعة الحرارية وتصدير PDF يستخدمان سجلات المحاسبة الحقيقية، دون تغيير القيم المخزنة.
- نسخة موظف البيع: أضيفت شاشة تقارير ضمن الشريط السفلي، وتقتصر بياناتها على العمليات التي يملكها موظف البيع وأرصدة الحسابات المتاحة من الرئيسي.
- نسخة موظف البيع: تمت إضافة مُصدّر PDF محلي إلى تطبيق Android باستخدام مُحرّك PDF المضمن من الرئيسي، مع مشاركة ملف PDF عبر نافذة النظام.

## الإصدارات
ويندوز 3.5.68؛ أندرويد الرئيسي 3.5.69؛ موظف البيع 3.5.69-field-pos؛ المستقل 3.5.66.

## GitHub
- لم يتغير معرّف الحزمة أو قاعدة البيانات أو مسار تخزين البيانات.
- استخدم مستودع ويندوز مع ملف ZIP واحد فقط، وأبق ملف البناء الحالي الذي يتعرّف على اسم ZIP تلقائياً.
- عند تحديث أندرويد استخدم مفاتيح توقيع APK الأصلية ولا تحذف التطبيق المثبت أو بياناته.
- احتفظ بنسخة احتياطية من الحسابات والفواتير قبل تثبيت أي تحديث.
