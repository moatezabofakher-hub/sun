# المحاسب التقني — تحديث التصميم والموظفين 14-11-2026

- حذف موظف البيع متصلاً أو غير متصل: حماية بكلمة السر، وإلغاء فوري للصلاحية على الرئيسي، دون محو الفواتير التاريخية. يعمل رفض الجهاز في محاولات المزامنة اللاحقة.
- إذا لم تكن كلمة سر للحماية، تُفتح شاشة إعداد كلمة السر وأسئلة الأمان قبل الحذف.
- يظهر أعلى التطبيق الرئيسي عدّاد الموظفين الذين نجحت المزامنة المصادق عليها لهم خلال آخر 40 ثانية (مؤشر تقريبي، وليس اتصال WebSocket دائمًا).
- استبدال الكلمات الظاهرة «المندوب» بـ«موظف البيع»، دون تغيير أسماء الحزم أو البروتوكول أو المفاتيح القديمة.
- عرض الليرة السورية «ل.س» للمستخدم فقط مع إبقاء قيمة ISO SYP داخلياً داخل المستندات وبيانات API.
- تحسين الأزرار والأيقونات بخلفيات لامعة وتظليل ثلاثي الأبعاد وحالات تركيز واضحة.
- حذف شريط السلة/الإعدادات العلوي من نقطة البيع؛ الوصول لإعداداتها من ضبط الفواتير وبقي زر المسح ضمن اختيار المواد.
- **ويندوز فقط:** نقل شريط التنقل إلى ما دون الشريط العلوي، وتحسين حجم الأيقونات، ووضع نقطة البيع النقدية أولاً باليمين بشكل أبرز.
- **هاتف موظف البيع:** إبراز زر «مسح الباركود الرئيسي» داخل المزامنة؛ وهو في الحقيقة ماسح QR لربط الإدارة وليس ماسح باركود أصناف، والحفاظ على وظيفة الماسح QR نفسها.
- احتفظ بنسخة احتياطية قبل تثبيت أي تحديث. لا تمسح بيانات التطبيق، ولا تغيّر مفاتيح التوقيع الأصلية على Android.
- هذه مشاريع المصدر وليست APK/EXE جاهزة؛ يلزم بناؤها واختبارها على الأجهزة الحقيقية والطابعات واتصال المزامنة.
