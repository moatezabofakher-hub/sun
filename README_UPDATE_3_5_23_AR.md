# المحاسب التقني – الإصدار 3.5.23

هذا التحديث يعالج صعوبة العثور على تعديلات التقارير والحماية، ويضيف علامات واضحة للتأكد من أن نسخة APK الجديدة تحتوي على الملفات المحدّثة.

- الشاشة الرئيسية: زران واضحان لتقرير المواد المباعة وتقرير الديون؛ كل منهما يفتح التقرير المناسب مع زر «طباعة حرارية».
- التقارير: أسماء واضحة لطباعة مبيعات الأصناف حسب التاريخ ولطباعة الديون لنا / علينا.
- الضبط: رقم الإصدار 3.5.23 يظهر أعلى الصفحة، واختصاران للتقارير، ثم قسم «الحسابات المستقلة للشركات».
- حفظ الحماية: عند وجود كلمة سر محفوظة تطلب نافذة التحقق كلمة السر مباشرة؛ عند عدم وجودها تظهر رسالة واضحة لضرورة إعدادها مع سؤالَي الأمان.
- الفواتير المطبوعة: فواصل منقطة وترقيم الأصناف كما في 3.5.21؛ تقارير المبيعات تخصم المردود.

## التحديث
1. قبل أي تحديث، احفظ نسخًا احتياطية خارجية منفصلة لكل شركة وتحقق منها.
2. استبدل الملفات داخل مساراتها الأصلية في GitHub (لا ترفع ZIP فقط).
3. تحقّق من ظهور versionCode 30 في app/build.gradle.
4. شغّل Actions > Technical Accountant - Signed APK من الفرع main، ونزّل ملف الـ APK الناتج من عملية بناء جديدة.
5. بعد التثبيت افتح «الضبط». يجب أن ترى «إصدار التطبيق: 3.5.23». إذا لم يظهر، فالنسخة المثبتة لم تُحدّث.

التوقيع الدائم ومعرّف الحزمة وبنية البيانات لم تتغير. اختبار الكود لا يساوي اختبار تثبيت APK والطباعة على طابعة فعلية.
