# تحديث المحاسب التقني 3.5.8 — الرئيسية وتقييم الجرد

## الشاشة الرئيسية
- إزالة ملخصَي «رصيد الصندوق» و«ديون لنا/علينا» من أعلى الصفحة الرئيسية فقط؛ تبقى البيانات والتقارير والحسابات كما هي.
- تحويل زر الخروج أعلى يمين الرئيسية إلى زر «الضبط». الضغط عليه يفتح الضبط مباشرة.
- يبقى الزر نفسه «رجوع» في الصفحات الداخلية، ويعيدك خطوة إلى الخلف.
- إزالة بطاقة «الضبط» المكررة من شبكة اختصارات الرئيسية.

## جرد المستودع
- أضفنا بطاقة «القيمة الإجمالية للمواد بسعر التكلفة» فوق جدول الجرد.
- يمكن اختيار الليرة السورية SYP أو الدولار USD في البطاقة، ويُحفظ الاختيار.
- المجموع = مجموع (رصيد المادة في المستودع المختار × سعر تكلفة الوحدة الأساسية) بعد تحويل كل مادة لعملة التقييم بالسعر العام الحالي.
- خيار «إجمالي جميع المستودعات» يجمع الأرصدة دون احتساب المناقلات الداخلية مرتين.
- عرض كل صنف في الجدول بعملة التقييم نفسها.
- جمع المبالغ يتم قبل التقريب النهائي، والقيم الأصلية المخزنة لا تتغير.
- يتم إظهار تنبيه واضح إذا كان سعر الصرف غير صالح ويحتاج تصحيحاً.

## حماية البيانات
- لم نغيّر اسم قاعدة بيانات IndexedDB، ولا معرّف حزمة التطبيق الأساسية.
- لا تحذف التطبيق الحالي قبل تجربة APK الجديد أو إنشاء نسخة احتياطية محققة الاستعادة.
- للتحديث دون فقد البيانات، استخدم نفس معرّف الحزمة ومفتاح توقيع APK السابق.
- النسخة المنفصلة تستخدم معرّف حزمة مختلفاً كي يمكن تجربتها بجانب الأساسي.
- ملفات ZIP مشاريع أندرويد وليست تطبيق APK مبنياً؛ يمكن بناؤها عبر GitHub Actions.
