# تحديث واجهة المستودعات والمصاريف – المحاسب التقني 3.5.1

- أصبحت بطاقتا «المستودعات والمناقلات» و«المصاريف» بنفس خلفية وأبعاد وألوان بطاقات الوظائف الثانوية الأخرى في الصفحة الرئيسية.
- تم استبدال `fa-warehouse` (غير المتوفر في ملف الأيقونات المحلي) بـ `fa-box-open` المتوفر فعلاً.
- في الصفحة الرئيسية: «إضافة مستودع» و«إضافة مصروف» للدخول مباشرة إلى نموذج الإضافة.
- أعلى صفحة المستودعات: «إضافة مستودع» و«مناقلة مواد»، وتنتقل الأزرار إلى النموذج المناسب مع وضع التركيز على الحقل.
- أعلى صفحة المصاريف: «إضافة مصروف جديد» وتعيد فتح نموذج إدخال نظيف، حتى عند تحرير مصروف سابق، دون تعديل أو مسح السجلات المحفوظة.
- أزرار الحفظ موجودة داخل نموذج كل عملية.
- **البيانات:** لم تتغير مفاتيح التخزين أو اسم قاعدة IndexedDB أو `applicationId`، والتغييرات خاصة بالواجهة وإصدار التطبيق. تحديث APK فوق التطبيق السابق يتطلب توقيعاً مطابقاً. قم بتصدير نسخة JSON قبل تثبيت أي تحديث؛ إذا رفض الهاتف تحديث APK فلا تحذف التطبيق القديم قبل تأمين النسخة الاحتياطية.

## بناء APK
1. فك ZIP وانسخ محتوياته كلها إلى مجلد مستودع GitHub `sun`.
2. في GitHub Desktop نفذ `Commit to main` ثم `Push origin`.
3. من صفحة GitHub Actions افتح آخر بناء ناجح وحمّل `app-debug.apk` داخل Artifact.
4. عند التثبيت، اختبر إضافة مستودع ومصروف ومناقلة، مع نسخة احتياطية محفوظة خارج التطبيق.

الاختبارات البرمجية المحلية لا تُغني عن تجربة APK حقيقية؛ البناء في GitHub لم يُجر لهذا الإصدار بعد.
