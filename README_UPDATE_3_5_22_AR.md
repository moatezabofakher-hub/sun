# المحاسب التقني – الإصدار 3.5.22

## ما الذي تغيّر؟
- عند الضغط على «حفظ إعدادات الحماية» مع وجود كلمة سر مُعدّة، تظهر تلقائياً نافذة التحقق من كلمة السر الحالية؛ دون الحاجة إلى فتح «تغيير كلمة السر».
- يبقى قسم الحماية مفتوحاً أثناء التحقق، ولا يتم حفظ أي تعديل عند الإلغاء أو إدخال رمز خطأ.
- يمكن تأكيد الرمز بزر «تحقق» أو Enter، وتنتقل العملية إلى الحفظ بعد التحقق الصحيح.
- عند إعداد كلمة سر لأول مرة تستمر آلية الإنشاء وأسئلة الأمان المعتادة.
- لا تُعرض خانة «كلمة السر الحالية» المكررة ضمن نموذج تغيير كلمة السر.
