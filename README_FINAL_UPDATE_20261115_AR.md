# تحسين وضوح أزرار التأكيد والحماية — المحاسب التقني

- ويندوز 3.5.69 وأندرويد الرئيسي 3.5.70.
- إصلاح الزر الأبيض غير المرئي «متابعة إلى التحقق من كلمة السر»: سببه عدم وجود bg-rose-700 في ملف Tailwind المجمع.
- الزر الخطر أصبح أحمر داكناً والنص أبيض؛ التحقق الأساسي أزرق تركواز داكن؛ الإلغاء بلون فاتح محدد الحواف.
- تحسين نوافذ تعيين كلمة السر، تحقق كلمة السر، تبديل الشركة، تأكيد الاستعادة، وإلغاء الإجراءات المشابهة.
- أزرار ثابتة CSS ذات أولوية مناسبة بدلاً من الاعتماد على الألوان غير الموجودة في ملف Tailwind.
- لا تغيير لسياسة التحقق من كلمة السر أو منطق حذف موظف البيع أو حفظ بيانات المستخدم.
- مشروع أندرويد المرفق يحتوي الرئيسي وموظف البيع. تعديل الألوان يخص الرئيسي فقط؛ موظف البيع يحتفظ بنسخته السابقة.
- قبل التثبيت خذ نسخة احتياطية، وحافظ على مفاتيح توقيع أندرويد الأصلية وبيانات ويندوز في مجلد المستخدم.
- ملفات ZIP مصادر كاملة وليست APK/EXE؛ يلزم إنشاؤها في GitHub قبل التثبيت.

## فتح نافذة ويندوز مع ظهور شريط المهام
- يفتح البرنامج مكبّراً إلى مساحة سطح المكتب المتاحة (Maximized)، دون Fullscreen؛ يبقى شريط مهام ويندوز ظاهراً.
- الزر F11 أصبح للتبديل بين تكبير النافذة واستعادة حجمها، لا لإخفاء شريط ويندوز.
- لا تغيير في مسار حفظ قاعدة البيانات ولا إعدادات الطباعة.
