# المحاسب التقني 3.5.10 — إصلاح إدخال أسعار المواد بدقة 0–4 منازل عشرية

- افتح **الضبط ← المواد ← عدد الخانات بعد الفاصلة العشرية للكميات والأسعار** وحدد 0 أو 1 أو 2 أو 3 أو 4.
- أثناء **إضافة مادة أو تعديلها** تقبل حقول **تكلفة الوحدة الكبرى ومبيعها** وأسعار **الوحدات الفرعية** العدد المختار من الخانات بعد الفاصلة.
- أصبح حساب أسعار الوحدات الفرعية من سعر الوحدة الكبرى **يتبع إعداد عدد المنازل العشرية** بدل التقريب المالي الافتراضي (سابقاً: USD منزلتان وSYP بدون كسور).
- يمكنك الآن، مثلاً، اختيار 4 ثم إدخال سعر 1.2345 وحفظه؛ وكذلك إذا كانت العملة ليرة سورية. ويظهر الرقم عند إعادة فتح المادة.
- يحدد الإدخال الحد الأقصى من المنازل المختارة؛ أما الأسعار القديمة فتبقى بقيمتها الأصلية ما لم تعدلها صراحةً.
- **تقريب المبالغ المحاسبية النهائية** مثل إجمالي الفاتورة والأرصدة لم يتغير: الدولار منزلتان، والليرة بدون كسور.
- تم الحفاظ على معرّف التطبيق الأساسي وقاعدة البيانات، والنسخة الاختبارية ذات معرّف مختلف. أنشئ نسخة احتياطية قبل التحديث، ولا تحذف النسخة الأصلية.
- ملف ZIP مشروع Android لرفعه على GitHub وبناء APK، وليس ملف APK مثبّتاً.
