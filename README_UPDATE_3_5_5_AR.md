# تحديث 3.5.5 — اللغتان والحماية والبصمة

هذه النسخة تبني على تحديث 3.5.4 المزوّد بقائمة لغة **العربية / English** وخيار **السماح ببيع المواد التي نفذ رصيدها**.

## تعديلات الحماية
- حذف لوغو الشركة من صفحة الضبط أو نافذة تعديل ترويسة الطباعة يتطلب رمز الحماية الصحيح دائماً.
- إذا لم يُنشأ رمز حماية بعد، يظهر تنبيه **يجب تعيين رمز الحماية أولاً** مع زر لنقلك مباشرة إلى إعداد رمز الحماية وأسئلة الأمان، ولا يُحذف شيء.
- تصفير قاعدة البيانات يتطلب رمز الحماية دائماً، ثم تأكيد الحذف النهائي؛ لا يؤدي تعطيل خيار «الحماية من حذف البيانات» إلى السماح بتصفيرها بلا رمز.
- قفل التطبيق: إذا فُعّلت بصمة أندرويد الأصلية مسبقاً، تظهر نافذة التحقق الحيوي فور فتح التطبيق أو العودة إليه، وزر **استخدام رمز الحماية** أسفلها. يفتح التطبيق فور نجاح البصمة أو كلمة السر. في حال عدم تمكين البصمة أو عدم دعم الجهاز لها، يظل إدخال الرمز متاحاً.
- عند تفعيل خيار «الحماية من حذف البيانات» سيُطلب رمز الحماية أيضاً قبل حذف السجلات الفردية (مثل المواد والفواتير)؛ أما التصفير الكامل وحذف اللوغو فهما محميان دائماً.
- في الوضع الإنكليزي، تُترجم نصوص القفل ورسائل إعداد الحماية الجديدة ونافذة Android BiometricPrompt، مع إبقاء النصوص والبيانات المسجلة في قاعدة البيانات دون تعديل.

## المحافظة على البيانات والتثبيت
- نفس applicationId ونفس قاعدة IndexedDB، ولم يتغير مخطط حفظ الفواتير أو البيانات. ملفات ZIP هي مشروع مصدر لأندرويد عبر GitHub Actions وليست APK جاهزاً.
- لتحديث التطبيق المثبت على الهاتف دون فقدان البيانات، يجب استخدام **نفس مفتاح توقيع APK** السابق ونسخة ذات versionCode أعلى. نسخة الاختبار لها معرّف حزمة مختلف ويجب اختبارها منفصلة عن التطبيق الأساسي.
- خذ نسخة احتياطية JSON محلية قبل تثبيت أي تحديث. اختبر النسخة الجديدة على نسخة من بياناتك أولاً.

> تنبيه للتوقيع: تنزيل APK من GitHub Actions موقَّع تلقائياً بمفتاح Debug مؤقت إذا لم تضبط توقيعاً ثابتاً. قد لا يتمكن من تحديث نسخة قديمة دون اختلاف التوقيع؛ لا تحذف التطبيق أو تمسح بياناته لحل هذه المشكلة. استخدم مفتاح التوقيع الأصلي لتحديث نفس الحزمة.
