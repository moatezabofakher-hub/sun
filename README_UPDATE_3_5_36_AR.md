# تحديث المحاسب التقني 3.5.36 وتطبيق المندوب 1.2.6

## ما تغيّر في هذا الإصدار

**طباعة المندوب:** أصبحت فواتير المبيعات والمردود في تطبيق المندوب ترسم بالطريقة نفسها المستخدمة في نسخة الإدارة (نفس ترويسة الشعار، اسم الشركة ورقمها وعنوانها، ورقة الطباعة، حجم الخط، أعمدة الأصناف، الإجماليات والملاحظة الختامية). تصدر هذه البيانات من **الرئيسي** عبر ملف التجهيز أو المزامنة المحلية المشفرة، وتُحدّث عند الاتصال. تم تمرير خيار عدد الخانات العشرية للأسعار والكميات أيضاً. لا يُسمح للمندوب بتعديل بيانات شركة الإدارة أو تغيير الفواتير المحفوظة عند تحديث الشعار.

**التقارير في الرئيسي:** تغيّر اسما زرّي الصفحة الرئيسية إلى «تقرير الديون» و«تقرير المواد». تبقى خيارات الديون (لنا/علينا)، وتقرير المواد المباعة (الفترة والمندوب). تظهر داخل النافذة أزرار «طباعة» و«حفظ PDF». عند اختيار PDF يحوّل أندرويد التقرير إلى مستند PDF عربي متعدد الصفحات، يفتح اختيار مكان حفظ الملف، ثم يفتح شاشة المشاركة مباشرة لإرساله بوسائل الهاتف. يُعرض رقم الصفحة وإجمالي العملتين؛ لا يتطلب اتصالاً بالإنترنت. خيار PDF المباشر يعمل في **APK الرئيسي**؛ تشغيل ملف HTML من متصفح عادي لا يتيح واجهة الحفظ والمشاركة الأصلية هذه.

**المستودعات والمناقلات:** يظهر سجل المناقلات أسفل الشاشة مباشرة. تصبح الإجراءات الرئيسية ثلاثة أزرار واضحة: «إضافة مستودع» كما في السابق، «مناقلة جديدة» لفتح فاتورة حركة مخزون بشبكة المواد والكميات والوحدات، و«المستودعات» لعرض الأسماء وتعديلها أو حذف المستودع الفارغ غير المرتبط بسجلات. فاتورة المناقلة لا تسجل مبيعات أو دفعات أو أرباح؛ تحفظ تحويل الكميات بين المصدر والوجهة وتظل قابلة للتعديل من السجل. لا يمكن حذف مستودع له أرصدة أو فواتير أو مناقلات سابقة.

## ملفات المشروع

- `app/` مشروع أندرويد الرئيسي بإصدار 3.5.36.
- `field_agent/` مشروع أندرويد المندوب بإصدار 1.2.6.
- `tests/` اختبارات السجلات والمزامنة والطباعة والواجهات.
- `.github/workflows/` إعدادات GitHub Actions للبناء كما في الحزمة السابقة.

## تثبيت التحديث مع بقاء البيانات

يجب **عدم حذف التطبيق المثبّت**. ارفع ملفات المشروع، ثم شغّل إجراء البناء في تبويب Actions لتحصل على APK. ثبّت تحديث كل من التطبيقين فوق النسخة الحالية **إذا كان توقيع APK مطابقاً لتوقيع النسخة المثبتة**؛ اختلاف التوقيع يتطلب التعامل معه قبل التثبيت، وليس حذف التطبيق. النسخ الاحتياطي المحلي قبل التحديث إجراء موصى به. لم يتغيّر معرّف حزمة أندرويد للتطبيقين أو أسماء قواعد البيانات أو بنية السجلات، ولم تُمسّ البيانات السابقة.

بعد التثبيت، عدّل بيانات الشركة في الرئيسي ثم اتصل بالمندوب حتى تنجح المزامنة الآلية؛ بعدها اطبع فاتورة للتأكد من ظهور بيانات الشركة المحدّثة. جرّب كذلك حفظ أحد التقريرين بصيغة PDF ثم اختر جهة المشاركة.

## الفحص

فحوصات JavaScript، وتناسق الحركات والمزامنة، وتحليل الصياغة لـ Java متاحة من `tests/`. لم يُبنَ ملف APK محلياً هنا بسبب عدم توفر Android SDK وGradle في بيئة تجهيز الملفات؛ يلزم بناء APK عبر GitHub Actions.
