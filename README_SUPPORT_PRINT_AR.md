# المحاسب التقني — الطباعة المباشرة ودعم واتساب

## التعديلات
- عند الضغط على «حفظ وطباعة بلوتوث»، تُحفظ الفاتورة أولاً، ثم تُجهّز وتُرسل للطباعة دون فتح شاشة المعاينة، وبعد محاولة إرسال الطباعة يعود التطبيق إلى الشاشة الرئيسية.
- زر «حفظ الفاتورة» وحده يحتفظ بطريقة عمله السابقة، بما في ذلك عرض المعاينة.
- في نافذة التفعيل أضيف «التواصل مع الدعم — مجموعة التقني للمحاسبة و المستودعات» مع رقمَي واتساب:
  - 00963932325577 — https://wa.me/963932325577
  - 00963968643771 — https://wa.me/963968643771
- الضغط على الرقم يحاول فتح واتساب المثبّت على أندرويد أولاً، ثم يفتح رابط الويب إن لم يتوفر التطبيق.
- يحتفظ المشروع بإصلاح الكاميرا والباركود والطباعة الأصلية والبصمة، دون تضمين مولّد التراخيص السري.

## طريقة رفع الملفات
1. في GitHub Desktop، اختر مستودع sun واضغط Fetch origin ثم Pull origin إذا ظهر.
2. اضغط Show in Explorer لفتح مجلد مستودع sun على الكمبيوتر.
3. فك ضغط ملف ZIP وانسخ **المحتويات الداخلية** كلها (app / tests / .github / ملفات الإعداد) داخل مجلد sun، مع الموافقة على الاستبدال.
4. ارجع إلى GitHub Desktop، واضغط Commit to main ثم Push origin.
5. افتح Actions وانتظر نجاح البناء؛ من Artifacts حمّل SAN-SHINE-Android-APK.zip، وافتح app-debug.apk بعد فك الضغط.

## مهم للبيانات
- احفظ نسخة احتياطية قابلة للاستعادة من التطبيق الحالي قبل أي تحديث.
- نسخة الاختبار الآمنة لها معرّف تطبيق مختلف فتثبت منفصلة وبياناتها مستقلة.
- نسخة التحديث لها معرّف التطبيق الأساسي، وقد يرفض أندرويد تثبيتها فوق APK قديم إذا اختلف مفتاح التوقيع؛ لا تحذف التطبيق القديم قبل التأكد من وجود النسخة الاحتياطية.

## الطباعة
- اطبع تجربة اتصال بالطابعة أولاً من «الطابعة والنسخ» مع التأكد من الاقتران، ثم جرّب «حفظ وطباعة» بفاتورة اختبار.
- العودة للرئيسية تتم بعد تجهيز/إرسال أمر الطباعة؛ **لا تعني** بالضرورة أن الورق طُبع فعلياً أو أن الطابعة استلمت الأمر. في حال فشل الطباعة يمكن إعادة طباعتها من سجل الفواتير.

## حدود الاختبار
الفحوص النصية والبرمجية لا تعوض بناء APK وتشغيله على هاتف أندرويد مع طابعة فعلية. لا يُرفق APK مبني مسبقاً؛ يتم بناؤه في GitHub Actions.
