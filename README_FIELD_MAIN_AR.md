# الإصدار الرئيسي — 3.5.25 (نسخة تجريبية)

تجربة فعلية لاستيراد ملفات عمليات المندوبين عبر المزامنة المحلية. أضيفت بطاقة «مندوبو التوزيع» إلى الرئيسية والضبط. لا ترفع الملف السري الخاص إلى GitHub.

لربط المندوب: أنشئ مستودع سيارة، انقل إليه البضاعة، أضف مندوبًا، صدّر ملف التجهيز إلى جهازه، ثم أصدر تفعيله بمفتاح PEM الخاص المحفوظ عند مالك الشركة فقط. يستورد الرئيسي ملف عمليات المندوب ويعرض معاينة ثم يرحلها مرة واحدة مع وسم اسم المندوب.

طريقة النقل الأولى ملفات JSON عبر Quick Share أو بلوتوث أو USB؛ الاتصال التلقائي Wi-Fi المباشر غير منفذ بعد. لا تستخدم في حسابات الإنتاج قبل اختبار حقيقي واستعادة النسخ الاحتياطية.
