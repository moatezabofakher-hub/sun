## التعديلات
1. ويندوز: حل رسالة «BarcodeDetector غير مدعوم». أصبح البناء يحزم قارئ ZXing محلياً ليعمل بكاميرا Windows دون اتصال إنترنت أثناء المسح. يبقى قارئ USB-HID مدعوماً؛ يجب منح الكاميرا إذن النظام.
2. التاريخ: تُعرض خانة الفاتورة على شكل YYYY-MM-DD واضح إلى جانب الوقت بدلاً من عنصر datetime-local ذي الرموز المضللة. يظل تاريخ الفواتير القديمة محفوظاً ما لم تعدله.
3. التسعير أثناء البيع (ويندوز، أندرويد الرئيسي، المستقل فقط): اختيار واضح «حسب إعدادات الحساب / الجملة / المركز / المستهلك» داخل فاتورة المبيعات. يؤثر على الأصناف المسعّرة تلقائياً ولا يلغي الأسعار المعدّلة يدوياً. لا يتغير سعر الحساب الأساسي أو أي فاتورة أخرى.
4. أندرويد الرئيسي: عنوان «المحاسب التقني» أصبح أعلى في المنتصف، وعداد موظفي البيع أسفله، دون تغطية العنوان. لا تغيير في عداد الموظف سوى موضعه.
5. نسخة موظف البيع بقيت دون خيار تسعير إضافي؛ جرى رفع رمز الإصدار ضمن المشروع الموحد فقط للتوافق مع بناء التحديث.

## مهم قبل البناء والتثبيت
- هذه ملفات مصدر كاملة، لا تحتوي على EXE أو APK جاهز. يُستخدم GitHub Actions لتوليد ملفات التثبيت.
- احفظ نسخة احتياطية من كل برنامج أولاً، ولا تحذف التطبيق المثبت أو بياناته.
- توقيع APK يجب أن يكون بنفس مفتاح التوقيع المستخدم في التثبيت السابق؛ وإلا فلن يقبل أندرويد التحديث فوق التطبيق المثبت.
- في ويندوز، يحتاج بناء قارئ الكاميرا الجديد إلى تنزيل @zxing/browser ومكتبة esbuild بواسطة npm أثناء GitHub Actions. بعد البناء يكون المسح محلياً Offline، دون إرسال الكاميرا للشبكة.
- اختبارات المصدر ناجحة؛ لم يُختبر تشغيل الكاميرا أو تثبيت النسخ على الأجهزة الحقيقية في هذه الجلسة.

تجد EXE ضمن Artifacts إذا نجح البناء.
