# تحديث المحاسب التقني 3.5.35 / تطبيق المندوب 1.2.5

## أولاً: أرصدة العملاء في تطبيق المندوب
- يرسل التطبيق الرئيسي أرصدة العملاء المنفصلة بالليرة السورية (SYP) والدولار (USD) داخل كشف المزامنة المشفّر.
- أضيفت صفحة «أرصدة الحسابات» في شاشة المندوب الرئيسية، مع بحث بالاسم وعرض الرصيد حسب العملة.
- تظهر الأرصدة عند اختيار عميل أثناء إعداد فاتورة البيع.
- يُحتسب أثر فواتير وسندات المندوب المحفوظة محلياً التي لم تشملها آخر لقطة من الرئيسي، دون احتساب العملية المرحّلة مرتين.
- الرصيد يُحدّث بعد كل مزامنة ناجحة، ولا يُعد رصيداً آنياً لجميع الأطراف في غياب الاتصال؛ يُعرض تاريخ الكشف.

## ثانياً: شاشة المبيعات لدى المندوب
- أعيد ترتيب إنشاء فاتورة البيع والمردود بأسلوب شاشة الرئيسي: رأس فاتورة مختصر، العميل والتاريخ، تبديل العملة، الدفع النقدي أو الآجل أو الجزئي، وشبكة أصناف قابلة للبحث حسب المجموعة.
- صور المواد المصغّرة (عند توافرها وحجمها المناسب)، زر × لإنقاص الاختيار، تعديل الوحدة والكمية والسعر، حسم عام وضريبة، وصافي ومدفوع ومتبقٍّ.
- زرا «حفظ الفاتورة» و«حفظ وطباعة بلوتوث» مع الترحيل المحاسبي السليم للحسم والضريبة.
- يحتفظ تطبيق المندوب بتقييد حركة مخزون سيارة المندوب ومنع تغيير العمليات المحفوظة بصمت بعد التزامن.

## ثالثاً: طباعة التقارير
- أزيلت خيارات طباعة ملخص المبيعات والديون من صفحتي التقارير والإعدادات؛ بقيت خيارات الطباعة على الرئيسية مع نموذج خيارات التقرير.
- يمكن فتح صفحات التقارير للعرض دون زر طباعة فيها.

## رابعاً: حذف المندوب غير المتصل
- يمكن اختيار «حذف المندوب» حتى وهو غير متصل؛ يتطلب التحقق من كلمة سر حماية تطبيق الرئيسي.
- يُؤرشف المندوب ويُمنع من التزامن بعد الحذف، وتُحفظ السجلات المحاسبية التي سبق ترحيلها.
- **تنبيه:** لا يمكن سحب التفعيل فوراً من هاتف منفصل عن الشبكة؛ توقف قبول العمليات الجديدة يُطبق عند محاولة المزامنة التالية. لهذا يجب ترحيل كل الحركات القديمة أولاً إذا كانت مطلوبة.

## أمان البيانات والتثبيت
- لم تتغير أسماء حزم أندرويد ولا مفاتيح IndexedDB. لا تحذف التطبيقين القديمين قبل أخذ نسخ احتياطية.
- يجب بناء التطبيقين وتحديثهما معاً، والتوقيع بمفاتيح التوقيع نفسها إذا أردت تثبيتهما فوق النسخ الحالية.
- أُجريت اختبارات JavaScript للمشروع، منها اختبار أرصدة العميل غير المرحلة والحسم والضريبة وترحيل فاتورة المندوب، وفحص بنية المشروع. يبقى اختبار نسختي APK على هاتفين فعليين ضرورياً.

## البناء على GitHub
1. المشروع الكامل: فك الضغط وارفع محتويات جذر ZIP إلى جذر المستودع.
2. حزمة التعديلات فقط: انسخ الملفات حسب مساراتها الموجودة داخل ZIP، مع الإبقاء على الملفات الأخرى كما هي.
3. نفذ Workflow البناء المعتاد في GitHub Actions للتطبيقين، ثم ثبّت كل إصدار بعد أخذ نسخة احتياطية.
