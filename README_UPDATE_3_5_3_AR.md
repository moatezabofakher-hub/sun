# المحاسب التقني – التحديث 3.5.3: قسم الضبط والتفعيل

## التعديلات
- تغيير اسم بطاقة «الطابعة والنسخ» في الصفحة الرئيسية إلى «الضبط» مع الاحتفاظ بزر فتح الإعدادات.
- إخفاء شارة الترخيص/التجربة من الشريط العلوي في جميع الصفحات.
- نقل بطاقة «تفعيل البرنامج والترخيص» إلى أول صفحة «الضبط»؛ تعرض رقم الجهاز، حالة التجربة/التفعيل، وزر إدخال رمز التفعيل أو عرض تفاصيله.
- بقاء إجراءات التحقق من التوقيع الرقمي والاتصال بالدعم كما هي دون تغيير.
- الإبقاء على خيارات طابعة البلوتوث، ترويسة الفاتورة، الحماية والنسخ الاحتياطي.
- رفع versionCode إلى 11 مع الاحتفاظ بمعرّف التطبيق نفسه لكل من نسختي التحديث والاختبار.

## الحفاظ على البيانات
- لم يتغير اسم قاعدة بيانات IndexedDB (`AlRaedAccountingERP_v2`) أو مفاتيح التخزين أو منطق المحاسبة.
- حزمة التحديث تحمل معرّف `com.sunshine.technicalaccountant` وتثبّت كتحديث للنسخة ذات المعرّف المطابق **إذا تطابق توقيع APK**.
- حزمة الاختبار المنفصلة تحمل معرّف `com.sunshine.technicalaccountant.warehousetest` وليست تحديثاً للتطبيق الرئيسي ولا تشارك بياناته.
- قبل أي تثبيت، استخرج نسخة احتياطية JSON واحفظها خارج التطبيق. لا تحذف التطبيق الموجود؛ توقيع مختلف يمنع التحديث فوقه، وحذفه قد يمحو البيانات.

## البناء من GitHub
فك الضغط وارفع **محتويات** الحزمة إلى جذر المستودع (مجلد `app` و`.github` و`tests` وغيرها)، ثم افتح GitHub Actions وحمّل ملف APK بعد نجاح البناء. لا ترفع ملف ZIP وحده.
