# المحاسب التقني 3.5.7 — أقسام الضبط والمنازل العشرية للمواد

## ما الجديد؟

- **الضبط** أصبح 10 فئات مطوية تُفتح وتُغلق بالنقر، وتبقى الفئة المفتوحة عند حفظ اختيار أو تغيير اللغة.
- **الطباعة**: اقتران البلوتوث، طريقة الاتصال، قياس الورق، وحجم خط الفاتورة.
- **الفواتير**: تحديد العملة الافتراضية للفواتير الجديدة (USD/SYP)، والنوع الافتراضي المعروض في سجل الفواتير (مبيعات/مشتريات/الكل). يبدأ السجل بتاريخ اليوم، مع إمكانية تغيير الفلاتر.
- **المواد**: السماح ببيع المواد غير المتوفرة، وعدد الخانات بعد الفاصلة العشرية للكمية (0 أو 1 أو 2 أو 3 أو 4؛ الافتراضي 2). يستخدم الإعداد في عرض كميات المواد والأرصدة والمناقلات والفاتورة المطبوعة، ولا يغيّر القيم المخزنة أو حسابات الربح أو جرد الكميات.
- **إعدادات الشركة**: اللوغو واسم الشركة ورقم الهاتف والعنوان والملاحظة الختامية.
- **الحماية**: رمز PIN، أسئلة الأمان، قفل التطبيق والبصمة، والتحقق عند الحذف.
- **النسخ الاحتياطي**: التصدير والاستعادة والنسخ التلقائي المحلي وGoogle Drive.
- **اللغة**: العربية / English، **العملة وسعر الصرف**، **التفعيل والترخيص**، و**إدارة البيانات** (تصفير شامل محمي) في أقسام منفصلة.

## الحفاظ على البيانات

- لم يتغير اسم IndexedDB (`AlRaedAccountingERP_v2`) ولا المخطط أو رقم الإصدار الخاص بقاعدة البيانات.
- بقي معرّف حزمة APK الأساسية كما هو؛ ارتفع versionCode إلى 15. يلزم **نفس مفتاح توقيع APK المثبت** للتحديث المباشر دون مسح البيانات.
- خذ نسخة يدوية من البيانات قبل تحديث التطبيق، ولا تحذف النسخة القديمة.
- النسخة الآمنة Safe Test تعمل بمعرّف حزمة مستقل ولا تشارك البيانات مع النسخة الأساسية.

## ملاحظة عن المنازل العشرية

عدد المنازل العشرية يؤثر فقط في **طريقة عرض الكميات** وليس دقة الحسابات المالية أو أسعار الفواتير. حتى إذا اخترت خانة واحدة، فإن قيمة المخزون الأصلية تحتفظ بجميع الكسور المحفوظة. يمكن الرجوع إلى 4 خانات لإظهار تفاصيل أكثر.

## التشغيل

ارفع محتويات ZIP إلى المستودع في GitHub، وشغّل GitHub Actions للبناء. هذا ZIP هو **مشروع أندرويد** وليس APK جاهزاً. ينبغي إجراء تجربة فعليّة على الهاتف قبل استخدامه على بيانات العمل.
