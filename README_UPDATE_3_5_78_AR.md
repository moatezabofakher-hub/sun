# التقني للمحاسبة — تحديث 3.5.78

## التغييرات

- إزالة خيار تغيير لغة الواجهة من الكمبيوتر والرئيسي والمندوب والمستقل، وإلغاء تحميل محرك الترجمة الإنجليزية من واجهات التشغيل.
- اعتماد واجهة عربية ثابتة. لا تتغير أسماء العملاء والمواد وقيود الدفاتر، ولا تمس التغييرات قواعد البيانات الموجودة.
- إبقاء **حجم الخط** خياراً مستقلاً في ضبط الكمبيوتر، ويُحفظ عند الضغط على حفظ في مجموعته؛ ويلغي زر إلغاء التغيير غير المحفوظ.
- تعديل تمرير الشاشة الرئيسية في تطبيقَي أندرويد الرئيسي والمستقل: أصبحت منطقة المحتوى تمريرية مستقلة بارتفاع الجهاز، مع مساحة مقاسة لشريط الأيقونات السفلي، ليظل الوصول إلى **إنشاء مستودع** و**إضافة مصروف** ممكناً فوق الشريط.
- المحافظة على ربط QR والمزامنة المحلية، والنسخ الاحتياطية، وطباعة البلوتوث، والمزايا السابقة دون إلغاء وظائفها.
- تحديث أرقام الإصدارات: Android الرئيسي 3.5.78 (code 83)، المندوب 3.5.78-field-pos (code 39)، المستقل 3.5.78 (code 27)، Windows 3.5.78.
