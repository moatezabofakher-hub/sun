# المحاسب التقني 3.5.48 — تحديث الصفحات المباشر ونافذة خروج مختصرة

## التطبيق الرئيسي
- بعد استقبال عمليات المندوب والموافقة على حفظها عبر Wi-Fi أو ملف العمليات، تُحدث الصفحة المعروضة تلقائياً دون الخروج منها أو الرجوع إليها.
- يشمل ذلك الرئيسية والفواتير والحسابات والسندات والتقارير وصفحات المندوب والإشعارات والجرد؛ تبقى الفترة والمندوب ونوع التقرير كما كانت قبل المزامنة.
- يُحفظ موضع التمرير وعبارة البحث المستخدمة في القوائم؛ لا تُقطع عملية تحرير فاتورة أو سند ولا تستبدل حقول إدخال نشطة. إذا كانت نافذة أو عملية تحرير مفتوحة، يؤجل التحديث حتى إغلاقها أو الانتقال إلى صفحة عرض آمنة.
- تنبيه عدد العمليات والإشعارات غير المقروءة يُحدَّث مع التزامن.
- نافذة تأكيد الخروج بتصميم أزرق-أخضر متناسق مع التطبيق وزرين: «البقاء» و«خروج»؛ بدون الشرح المطوّل.
- أخفي السطر التوضيحي أسفل عنوان الشاشة وتوضيحات أقسام الرئيسية وبطاقات العمليات السريعة؛ بقيت أسماء الأقسام والأزرار ظاهرة.

## سلامة البيانات والتثبيت
- لا تغييرات في قاعدة البيانات أو الأرصدة أو بروتوكول المزامنة أو تطبيق المندوب.
- التحديث يخص التطبيق الرئيسي فقط، ويجب تثبيت APK بنفس توقيع الإصدار المثبت ونسخ البيانات احتياطياً قبل التحديث.
- الاختبارات البرمجية ليست بديلاً عن الاختبار على هاتف فعلي أثناء مزامنة فعلية.
